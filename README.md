# Ghassan Bin Zia App Store

This store starts with ZERO apps. Nothing fake is included.

- index.html = public store
- admin.html = owner control panel
- apps/apps.json = published catalogue
- apps/apk/ = APK storage
- apps/icons/ = icon storage

Use GitHub Pages for hosting. The admin uploader uses the GitHub repository Contents API and is intended for files under 100 MB.
